# WiFi Admin
Android app (English/Bangla) to manage a Tenda AC5 router: device list, block/unblock, speed limit.
No server needed: the app talks to the router directly over your home WiFi.
Sign in with your app password, or with a fingerprint saved on the phone (Android 9+; turn it on in Settings after your first sign-in).
Download the APK from the Releases page. `laptop-server/` is an optional laptop version.
